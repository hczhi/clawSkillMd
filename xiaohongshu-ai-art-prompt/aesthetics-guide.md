## 一、颜色词汇库进阶

### 1.1 避免模糊描述

❌ **错误示例**:
- "colorful" (太笼统)
- "beautiful colors" (无意义)
- "nice palette" (不具体)

✅ **正确用法**:
- "pastel pink and mint green gradient"
- "vibrant coral with electric blue accents"
- "muted earth tones with warm ochre highlights"

## 四、构图法则详解

### 4.1 三分法 (Rule of Thirds)

**原理**: 将画面横向和纵向各分为三等分，形成九宫格，主体放在交点或线上

**应用提示词**:
```
rule of thirds composition, subject placed on right vertical line
off-center framing with negative space on left side
intersection point focus where two grid lines meet
balanced asymmetry following third divisions
```

**适用场景**:
- 人像摄影 - 眼睛对齐顶部横线
- 风景摄影 - 地平线对齐下三分之一
- 产品拍摄 - 主体偏离中心制造动势

### 4.2 黄金螺旋 (Golden Ratio Spiral)

**原理**: 按 1:1.618 比例形成的斐波那契螺旋引导视线

**应用提示词**:
```
golden spiral composition guiding eye through frame
Fibonacci spiral aligning main focal points
logarithmic curve drawing attention naturally
organic flow following mathematical proportions
```

**适用场景**:
- 美食摄影 - 食物摆放沿螺旋轨迹
- 建筑摄影 - 楼梯/走廊形成螺旋引导
- 艺术插画 - 人物姿态形成曲线动线

### 4.3 对称构图 (Symmetry)

**原理**: 左右或上下镜像平衡，创造稳定庄严感

**应用提示词**:
```
perfect symmetrical composition mirrored center axis
reflection symmetry in water creating double image
architectural symmetry emphasizing order and balance
fractal symmetry repeating geometric patterns
radial symmetry radiating from central point
```

**适用场景**:
- 建筑设计 - 古典宫殿立面
- 倒影拍摄 - 水面天空镜像
- 产品特写 - 展现完美平衡美感

### 4.4 引导线构图 (Leading Lines)

**原理**: 利用线条元素引导观众视线至主体

**应用提示词**:
```
strong leading lines converging toward subject
perspective lines drawing eye into depth of frame
curving pathways creating S-shaped visual journey
railroad tracks disappearing to vanishing point
bridges arches forming overhead framing elements
```

**适用场景**:
- 街道摄影 - 斑马线/人行道引导
- 风景摄影 - 河流/小路延伸
- 室内摄影 - 天花板线条汇聚

### 4.5 框架构图 (Framing)

**原理**: 用前景元素构成画框聚焦主体

**应用提示词**:
```
frame within a frame technique using architectural elements
natural frame formed by tree branches overhead
window frame isolating subject from busy background
doorway creating foreground border around scene
archway tunnel perspective enclosing the view
```

**适用场景**:
- 人像摄影 - 门窗门廊框架
- 风景摄影 - 岩石洞/树冠天然框
- 故事感照片 - 通过框架制造窥视感

### 4.6 负空间 (Negative Space)

**原理**: 大面积留白突出主体，创造呼吸感和想象空间

**应用提示词**:
```
minimalist composition dominated by empty negative space
solitary subject surrounded by vast plain expanse
breathing room around main element emphasizing importance
clean uncluttered background preventing visual noise
sparce composition allowing eye rest and contemplation
```

**适用场景**:
- 极简海报 - 大字报设计
- 高端品牌 - 奢侈品包装配图
- 情感表达 - 孤独/自由主题创作

### 4.7 视角选择

#### 平视 (Eye Level)
```
eye-level viewpoint creating relatable human perspective
straight-on angle capturing subjects naturally
ground-level shot maintaining viewer connection
neutral camera height establishing observational stance
```

#### 仰视 (Low Angle)
```
low angle shot making subject appear powerful dominant
worm's-eye view looking up from ground level upward
heroic perspective emphasizing stature and presence
towering buildings reaching skyward dramatically
```

#### 俯视 (High Angle)
```
high angle shot looking down at scene from above
bird's-eye view providing complete overhead coverage
omniscient vantage point surveying entire composition
intimate angle observing small subjects closely
```

#### 倾斜 (Dutch Angle)
```
tilted horizon line creating dynamic tension unease
Dutch angle introducing psychological discomfort
off-kilter composition suggesting chaos instability
diagonal orientation adding visual excitement
```

## 六、实战练习清单

### ✅ 每日练习建议

**周一：颜色练习**
- 尝试只用 3 种颜色描述一个场景
- 练习使用具体色值而非通用形容词
- 组合 2 种互补色进行视觉测试

**周二：氛围塑造**
- 用同一场景写出 3 种不同氛围版本
- 专注时间设定对情绪的影响
- 练习通过光线传递情感

**周三：质感探索**
- 选择 3 种不同材质并精细描述
- 添加光照如何影响材质观感
- 尝试老化和新物的对比描写

**周四：构图实验**
- 为同一个主体尝试 5 种构图方式
- 每种构图说明为什么这样选择
- 思考构图如何影响叙事角度

**周五：综合应用**
- 创建一个完整提示词包含 6 要素
- 确保颜色、氛围、质感、构图协调统一
- 验证逻辑连贯性和视觉合理性

**周末：案例复盘**
- 分析优秀作品中的美学运用
- 总结可借鉴的构图技巧
- 记录自己的发现和改进点

## 七、常见美学误区

### ❌ 误区 1: 堆砌华丽辞藻
```
错误："gorgeous magnificent beautiful stunning amazing spectacular"
正确：具体描述每个元素的状态特征
```

### ❌ 误区 2: 矛盾的光线设定
```
错误：同时出现"sunny noon"和"candlelight evening"
正确：保持时间逻辑一致性
```

### ❌ 误区 3: 风格混乱混合
```
错误：写实摄影 + 像素艺术 + 水彩同时存在
正确：确定主风格后适度补充次要元素
```

### ❌ 误区 4: 过度细节导致失衡
```
错误：超过 5 个互不相关的细节描述
正确：精选 2-3 个关键细节点缀即可
```

### ❌ 误区 5: 忽视色彩心理学
```
错误：冷色调用于美食产生食欲抑制
正确：根据内容属性匹配色彩温度
```
