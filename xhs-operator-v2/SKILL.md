## 🎯 **六大核心功能**

### A: 选题评分器 (Topic Evaluator)
**输入**: 选题方向/关键词  
**输出**: 
- ✅ 匹配度评分 (0-100)
- 🔍 优缺点分析
- 💡 3-5 个优化方向参考
- ⚠️ 潜在风险预警

**方法论基础**:
- CTR×AVD 双指标理论
- 平台数据验证（搜索热度）
- 竞品爆款模式识别
- 实战案例数据对照 (@是官官的家)

---

### B: 标题&内容评分器 (Content Auditor)
**输入**: 完整笔记文案 + 封面描述  
**输出**:
- 📊 STEPPS 六维评分表
- 🤖 AI 化程度检测 (0-10 分)
- 👤 人设一致性检查 (@程序员小智标签)
- ✍️ 具体改写建议 + 优化版本对比

**方法论基础**:
- 前 30 秒法则 (首图 + 开头 Hook)
- 一句话测试 (标题是否吸引人点击)
- 自点击测试 ("如果这是我刷到的，我会点吗？")
- **痛点场景化**: "卖生活不卖参数"原则
- **具象化策略**: 毛坯 roomtour 成功公式

---

### C: 装修领域知识问答 (Decoration Q&A)
**输入**: 装修/家居相关问题  
**输出**:
- 🏠 基于本地数据库的专业解答
- 📐 户型图 API 数据联动查询
- 🧾 报价参考表实时检索
- 💡 避坑指南结合提问场景

**技能集成**:
- `decoration-v5` 核心知识库
- `floor-plan-analysis` 户型计算
- `renovation-db` 费用数据

---

### D: 发布后复盘分析器 (Post-Mortem Analyzer)
**输入**: 发布后的数据指标  
**输出**:
- 📈 STEPPS 各维度表现诊断
- 🔄 A/B 测试建议列表
- 📅 选题方向持续性评估
- 📝 下周改进清单

**关键问题**:
- "为什么这篇数据好？" → 找到可复制的成功模式
- "为什么那篇数据差？" → 避免重复踩坑

---

### E: AI 化程度检测器 (Anti-AI Checker)
**输入**: 任何文本内容  
**输出**:
- 🚨 AI 特征定位（高概率段落）
- 😐 模板化表达识别
- 💬 情绪浓度分析
- 🗣️ 口语化改写方案

**检测维度**:
- ❌ "首先/其次/最后"等逻辑词频率
- ❌ 说教语气占比 (>30% 报警)
- ❌ 完美排版的"机械感"
- ✅ 个性化符号使用 (emoji/口语词/吐槽)
- **特别关注**: 专业术语堆砌 vs 生活痛点翻译

---

### F: 数据预测防幻觉校验器 (Data Validator)
**输入**: 预测需求 + 历史数据上下文  
**输出**:
- 📊 保守区间预测 (如 "预计 3k-8k 曝光")
- 📚 数据来源标注 (置信度说明)
- ⚠️ 不确定性提醒
- 🛡️ 假设条件列表

**原则**:
- ✅ 宁可不说，不说假话
- ✅ 提供范围而非精确值
- ✅ 标注所有假设前提
- ❌ 严禁编造看似精确实则虚构的数字

---

### G: 人设一致性检查器 (Persona Verifier) ⭐新增
**输入**: 完整的笔记内容  
**输出**:
- 👤 @程序员小智的人设匹配度 (0-100)
- 💻 程序员思维元素评分 (数据/工具/严谨)
- 🏗️ 装修小白视角评分 (吐槽/学习过程)
- 🤖 AI 爱好者创新评分 (自动化/数据分析)
- 💡 不一致处指出 + 修改建议

**人设标准**:
```markdown
✅ 有程序员的严谨:
  - 用数据说话 (预算表/面积测算)
  - 推荐实用工具 (Python/Excel/API)
  - 逻辑清晰的结构化表达

✅ 有装修小白的真实感:
  - 展示失败经历 (被坑/踩雷)
  - 表达纠结情绪 (选择困难)
  - 成长记录 (从不懂到懂)

✅ 有 AI 爱好者的创新:
  - 自动化工具分享
  - 数据分析可视化
  - AI+ 装修应用场景

❌ 人设模糊的信号:
  - 全是技术术语无情感
  - 完美人设像广告号
  - 没有个人特色记忆点
```

## 🧠 **核心心智模型**

### 1️⃣ **CTR×AVD 双轮驱动**
- **CTR (点击率)** = 封面吸引力 + 标题冲击力
- **AVD (观看时长)** = 前 30 秒 Hook + 内容价值密度
- **公式**: 流量推荐 ∝ CTR × AVD × 互动率

### 2️⃣ **阶梯递进原则**
每页图文/视频都要升级刺激强度：
- P1: 抓眼球 (视觉冲击)
- P2-P4: 给干货 (价值密度)
- P5: 留悬念 (引导互动)
- P6: 促行动 (关注/收藏)

### 3️⃣ **真实性 > 完美性**
- 展示失败 > 只晒成功
- 表达纠结 > 假装全能
- 带情绪 > 冷冰冰的教程

### 4️⃣ **卖生活，不卖产品** ⭐ **新增重点**
- 用户买的不是"装修服务",而是"更好的生活状态"
- 把专业术语翻译成"她受的罪":
  - "动线紊乱" → "每天绕路八百圈"
  - "收纳缺失" → "找件衬衫要翻半小时"
  - "防水不到位" → "每次洗澡变落汤鸡"

### 5️⃣ **替她说出委屈**
- 共情 > 说教
- 提问揭穿 > 参数罗列
- 让她觉得"你懂我"而不是"你在推销"

### 6️⃣ **实战案例验证** ⭐ **最新添加**
参考@是官官的家的成功路径:
- **第一阶段**(试水): 纯知识输出 → 流量惨淡 (<200 浏览量)
- **第二阶段**(转折): 借势风口 + 真实记录 → 单篇 42 浏览
- **第三阶段**(爆发): 图文转视频 + 三大爆款秘籍 → 一夜涨粉 1w
- **第四阶段**(稳定): 数据驱动迭代 → 形成可持续增长

**她的四大秘籍**:
1. **毛坯 roomtour**(具象化) → "宝格丽套房""哈利波特书房"
2. **创意转场视频**(情绪化) → 空房间录转场增加幻想期待
3. **数据锚定效应**(数字敏感) → "500W 踩坑""2000㎡别墅"
4. **数据分析驱动迭代** → 每周复盘后台数据优化策略

## 🛠️ **使用方式**

### 场景 1: 我想写一篇关于"装修合同避坑"的笔记
```text
>> 帮我评估这个选题
[系统] -> A: 选题评分器
→ 判断热度、竞争度、可操作性
→ 输出：推荐指数 87/100
→ 优点：刚需高频 / 缺点：竞争激烈
→ 建议切入点："签合同时我差点被骗 3 万..."
```

### 场景 2: 我写好了草稿但担心太 AI
```text
>> 帮我看看这篇有没有 AI 味
[粘贴全文]
[系统] -> E: AI 化检测器 + B: 内容评分器
→ AI 特征评分：6.2/10 (偏高)
→ 问题定位：第 3 段"首先/其次"太生硬
→ 改写建议：改成交互式故事叙述
→ 输出优化版对比
```

### 场景 3: 我的笔记发布后数据不好
```text
>> 复盘一下昨天的数据
[粘贴数据：浏览量 1200, 互动 89, 涨粉 3]
[系统] -> D: 复盘分析器
→ STEPPS 得分：社交货币低 (45%) / 情绪不足 (30%)
→ A/B 建议：封面换真人出镜 / 标题增加冲突感
→ 规律发现：「对比型」选题比「教程型」好 2.3x
```

### 场景 4: 写家装文案不知道如何切入
```text
>> 如何用痛点写作法写橱柜收纳？
[系统] -> 引用 pain-point-copywriting.md
→ 提供对照表：专业术语 → 生活痛点
→ 生成 3 个不同角度的文案示例
→ 自检 Checklist 确保符合"卖生活"原则
```

### 场景 5: 想参考成功案例快速起号
```text
>> 借鉴@是官官的家的成功经验
[系统] -> 引用 case-study-home-blogger.md
→ 提取四大爆款秘籍
→ 生成你的差异化定位建议
→ 制定启动期行动计划 (Day 1-7)
```
