## 🤖 **AI 化内容特征库**

### 🔴 **高概率 AI 标记 (出现即报警)**

| 特征 | 示例 | 替代方案 |
|------|------|----------|
| "首先/其次/最后" | "首先要注意...其次..." | "第一天被坑惨了→第二天学聪明了→现在回头看..." |
| "综上所述/总之" | "总之装修要慎重..." | "到现在我才明白..." |
| 完美排版的列表 | ✅1️⃣2️⃣3️⃣整齐对仗 | 口语化分段 + emoji 自然分布 |
| 说教语气 | "你要注意/你应该" | "我当时...后来我发现..." |
| 空洞结论 | "这是一个重要的经验" | "省了 4320 块，够买杯奶茶了🥤" |
| 标准化结构 | 标题 - 简介 - 正文 - 总结 | 碎片化表达 (像聊天一样) |
| 过度礼貌 | "希望对你有帮助/谢谢观看" | "有不懂的评论区问/一起避坑!" |

### 🟡 **中概率 AI 标记 (需优化)**

| 特征 | 示例 | 改进建议 |
|------|------|----------|
| 缺乏情绪词 | "今天去工地检查" | "今天气笑了😤工头又说要加钱" |
| 缺少数字细节 | "花了不少钱" | "花了 8,320 元，比预算超了 15%" |
| 无个人特色 | 通用装修建议 | 加上"#程序员小智"视角的吐槽 |
| 没有冲突感 | "事情进展顺利" | "差点放弃...但最后值了💪" |

## 📋 **自检 Checklist**

发布前逐条核对:

```markdown
□ 全文没有出现「首先/其次/最后」等逻辑连接词
□ 至少有 3 处具体的数字/时间/金额描述
□ 有真实的情绪表达 (愤怒/惊讶/感动/自嘲)
□ 有个人特色的语言 (口头禅/表情符号/吐槽)
□ 结尾不是标准化的「感谢关注」而是引导互动
□ 封面不是 AI 生成的完美图片而是真实场景拍摄
□ 文字不像教程而像朋友聊天
□ 至少有一处展示失败/纠结的经历
□ 有能证明真实性的小细节 (聊天记录截图/价格标签)
□ 读起来像在「讲故事」而不是「列要点」
```

## 🎯 **评分系统**

### AI 化程度检测器 (0-10 分)

```python
def ai_detection_score(text):
    issues = []
    
    # 逻辑词检测
    if count_logic_words(text) > 3:
        issues.append("逻辑词过多")
    
    # 情绪密度检测
    emotion_ratio = count_emotional_words(text) / len(text)
    if emotion_ratio < 0.02:
        issues.append("情绪浓度过低")
    
    # 具体细节检测
    has_numbers = any(re.search(r'\d+', text))
    if not has_numbers:
        issues.append("缺少具体数字")
    
    # 人称代词检测
    first_person_ratio = text.count('我') / len(text)
    if first_person_ratio < 0.01:
        issues.append("太少第一人称叙事")
    
    score = min(10, len(issues) * 1.5)
    
    return {
        'score': score,
        'threshold': '<3 分合格',
        'problems': issues,
        'suggestions': generate_fixes(issues)
    }
```

### 分级标准

| 分数 | 评价 | 处理方式 |
|------|------|----------|
| 0-2 | 非常真实 | ✅ 可直接发布 |
| 3-5 | 稍有 AI 味 | ⚠️ 建议优化 |
| 6-8 | 明显 AI 化 | 🔴 必须重写 |
| 9-10 | 纯机器生成 | ❌ 完全不能用 |
