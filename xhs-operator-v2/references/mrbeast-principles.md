## 🎯 **核心原则：零无聊时刻 (Zero Boring Moments)**

### 1️⃣ **每 30 秒一个刺激点**
```
Video Timeline:
0-5s:   Hook - 视觉冲击/悬念抛出
5-10s:  承诺价值 - "30 秒后告诉你答案"
10-30s: 第一次反转/惊喜
30-60s: 第二次升级
...
每 30 秒必须有一个「哇」时刻
```

### 2️⃣ **标题必须在 10 个字内让人兴奋**
**MrBeast 公式**:
```
[数字] + [反差] + [紧迫感] + [好奇心缺口]

示例:
❌ "如何省钱装修" → ✅ "花了$10,000 买教训！你绝对想不到..."
❌ "装修避坑指南" → ✅ "装修公司不敢说的 7 个秘密"
❌ "我家装修日记" → ✅ "第 14 天：被坑惨了...但现在值了"
```

**一句话测试**:
> "如果这是我刷到的，我会点吗？"

### 3️⃣ **自点击测试 (Self-Click Test)**
在发布前问自己 3 个问题：
1. 封面是否让人想停下滑动？(CTR 预测)
2. 开头 3 秒能否留住人？(AVD 预测)
3. 看完会想分享/收藏吗？(互动率预测)

## 🔥 **爆款元素拆解**

### A. **封面设计规则**

| 元素 | 要求 | 原因 |
|------|------|------|
| **人脸** | 大特写 + 夸张表情 | 触发镜像神经元 |
| **色彩对比** | 高饱和度 (黄/红/蓝) | 算法推荐权重 +20% |
| **文字** | ≤4 个字 + 描边效果 | 手机屏幕可读性 |
| **箭头/圆圈** | 指向关键区域 | 引导视觉焦点 |
| **前后对比** | Left ❌ Right ✅ | 冲突感提升点击 |

**我的应用**:
```
@程序员小智的人设封面:
✅ 真人出镜 (戴安全帽/拿卷尺)
✅ 工地实拍背景 (真实感)
✅ 大字标题 (3-5 字醒目色)
✅ 对比视觉 (左边❌右边✅)
```

### B. **Hook 设计公式**

**前 3 秒钩子类型**:

1. **数字冲击型**
   ```
   "花了 8 万块踩了 17 个坑..."
   "省下的钱够买台 iPhone 了💰"
   ```

2. **冲突对抗型**
   ```
   "工人说'这是行规'，但我不信邪😤"
   "装修公司要加钱？我直接怼回去!"
   ```

3. **好奇悬念型**
   ```
   "签合同时我差点被骗 3 万..."
   "最后发现是 3 厘米的误差..."
   ```

4. **情绪共鸣型**
   ```
   "第一次装修被骂哭了三次..."
   "程序员的执念：必须把这事搞明白"
   ```

### C. **阶梯递进节奏**

```
P1-P2: 抓眼球 (强视觉/强悬念)
P3-P4: 给干货 (密集信息量)
P5-P6: 升情绪 (共鸣/愤怒/惊喜)
P7:    促行动 (关注/评论/收藏)
```

**每个阶段的「刺激升级」策略**:
- P1: 视觉刺激 (封面/颜色/人脸)
- P2: 认知刺激 ("你知道吗？")
- P3: 情感刺激 ("我太生气了!")
- P4: 实用刺激 ("这个技巧能帮你省 X 万")
- P5: 社交刺激 ("转给需要的人")

## 📊 **数据驱动决策**

### 1️⃣ **CTR×AVD 双指标理论**

```
流量公式: 推荐曝光 ∝ CTR × AVD × 互动率

目标区间:
✅ CTR > 15%     (封面标题达标)
✅ AVD > 35 秒   (内容留住人)
✅ 互动率 > 8%   (引发共鸣)
```

**数据分析流程**:
```
发布后 1 小时: 只看 CTR (封面是否有效)
发布后 24 小时: 看 AVD+ 互动率 (内容质量)
发布后 7 天: 看长尾流量 (选题生命力)
```

### 2️⃣ **A/B 测试策略**

| 变量 | 测试项 | 预期收益 |
|------|--------|----------|
| 封面风格 | 真人 vs 纯图文 | CTR +12% |
| 发布时间 | 19:00 vs 21:00 | AVD +8% |
| 标题长度 | 8 字 vs 15 字 | CTR +5% |
| 标签组合 | 3 个 vs 7 个 | 搜索流量 +15% |

### 3️⃣ **爆款复盘方法**

**成功归因**:
```
Q1: 哪个元素贡献最大？
→ 如果是标题 → 强化标题能力
→ 如果是封面 → 优化视觉表达  
→ 如果是内容 → 复制叙事结构

Q2: 可复制的模式是什么？
→ 记录到案例库 → 下次复用
→ 标注适用场景 → 避免硬套
```

**失败诊断**:
```
低 CTR → 封面/标题问题
低 AVD → 开头 Hook 不够强
低互动 → 缺少提问/引导
```

## 🧠 **内容创作系统**

### **Step 1: 选题池构建**
```
来源:
① 平台热搜词 (每周更新)
② 竞品爆款追踪 (TOP10 模式)
③ 个人经验总结 (踩坑/学习过程)
④ 读者提问收集 (评论区挖掘)
```

### **Step 2: 热度验证**
```
检查项:
✅ 是否有相关关键词搜索趋势？
✅ 同类内容近期表现如何？
✅ 这个角度是否有人讲过？
```

### **Step 3: 差异化设计**
```
问自己:
"我和其他人讲同样的话题，有什么不同？"

差异化维度:
① 视角差异 (程序员 vs 设计师 vs 业主)
② 工具差异 (Python 自动化 vs 人工计算)
③ 叙事差异 (故事化 vs 教程化)
④ 证据差异 (数据截图 vs 口头描述)
```

### **Step 4: 执行清单**
```
发布前检查:
□ 标题通过一句话测试
□ 封面符合 3 秒原则
□ 前 30 秒有足够刺激
□ 结尾有明确引导动作
□ STEPPS 六维评分 > 70
□ AI 化检测 < 3 分
```
