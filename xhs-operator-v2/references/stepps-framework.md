# STEPPS 传播理论完整指南

> Jonah Berger《疯传》(Contagious: Why Things Catch On) 核心内容蒸馏

---

## 📚 **STEPPS 六原则详解**

### S - Social Currency (社交货币)

**核心问题**: "人们分享是为了让自己看起来更聪明/有趣/有品味"

**设计原则**:
```markdown
✅ 高社交货币 = "转了这个显得我很会过日子"
❌ 低社交货币 = "随便看看而已"
```

**执行技巧**:

| 策略 | 示例 | 效果 |
|------|------|------|
| **稀缺性暗示** | "只有前 100 人知道的秘密" | FOMO 心理 |
| **独家信息** | "装修公司不会告诉你的真相" | 知识优越感 |
| **实用价值** | "3 张表搞定全屋预算 PDF" | 利他获得感 |
| **身份认同** | "#程序员装修 #数据派博主" | 群体归属感 |

**案例对比**:
```
❌ 低社交货币:
"地板怎么选？大家要注意..."

✅ 高社交货币:
"我花了 3 个月研究，这份选购清单被赞爆🔥 
附：避坑检查表 (自取)"
```

---

### T - Triggers (触发器)

**核心问题**: "什么能让内容持续被想起？"

**设计原则**:
```markdown
把产品跟日常场景绑定
触发器频率 × 联想强度 = 回忆率
```

**我的赛道应用** (家装 +AI):

| 场景触发器 | 关联内容 | 笔记标题示例 |
|------------|----------|--------------|
| 下雨天发现渗水 | 防水经验 | "暴雨夜厨房漏水了...我当场崩溃😭" |
| 周末请朋友聚餐 | 厨房收纳 | "朋友来家里蹭饭才发现餐桌不够大💔" |
| 看到别人家亮灯 | 智能家居 | "隔壁装智能灯的第 7 天，我真香了✨" |
| 合同签完后悔 | 避坑提醒 | "签合同后第 3 天我就发现了这个陷阱⚠️" |

**触发器设计公式**:
```
高频场景 (每天发生) + 低记忆成本 (一句话就能想起) + 强情绪连接
```

---

### E - Emotion (情绪驱动)

**核心问题**: "人们分享内容的原因是什么？"

**高传播情绪排名**:
```
1. 😡 愤怒/不平      → "气死我了！"
2. 😂 愉悦/搞笑      → "笑到肚子疼"
3. 😢 悲伤/共情      → "谁懂啊...哭了"
4. 😱 焦虑/恐惧      → "再不看就晚了"
5. 🤩 惊讶/震撼     → "你绝对想不到!"
6. 🥰 温暖/感动      → "被暖到了"
```

**我的内容策略**:

```markdown
✅ 愤怒型 (适合踩坑揭露):
"工人说'这是行规'，但我不服输😤 
花了 3 天研究终于找到了证据!"

✅ 惊讶型 (适合知识科普):
"花了 2 万块的定制柜，拆封我直接报警🚨
原来这里藏着猫腻..."

✅ 共情型 (适合成长记录):
"第一次自己装修，被骂哭了三次...
但现在回头看，都值了💪"
```

**避免情绪平淡**:
```
❌ "今天去工地检查了一下"
✅ "在工地被工人怼哭了，但我学到了..."
```

---

### P - Public (可见性)

**核心问题**: "为什么有些人做的事情大家都在做？"

**设计原则**:
```markdown
看得到的东西容易被模仿
视觉辨识度越高 → 传播速度越快
```

**执行技巧**:

| 维度 | 标准 | 案例 |
|------|------|------|
| **封面风格** | 固定格式让人一眼识别 | 真人 + 安全帽 + 工地背景 |
| **视觉符号** | 建立个人标志性元素 | 橙色标签 #程序员装修 |
| **对比呈现** | Left ❌ Right ✅ | 直观可学 |
| **数字标注** | 明确进度增加真实感 | "已花 8 万/还剩 3 个坑" |

**品牌化建议**:
```
固定元素组合:
① 封面色调 → 暖色系 (橙黄为主)
② 字体风格 → 粗体 + 描边
③ 结尾口号 → "关注我，一起避坑"
④ 标签体系 → #程序员小智系列
```

---

### P - Practical Value (实用价值)

**核心问题**: "人们爱分享什么？"

**设计原则**:
```markdown
实用价值 = 解决的问题 × 获取难度

简单 + 有用 = 高分享率
复杂 + 无用 = 零传播
```

**内容类型规划**:

| 类型 | 示例 | 价值密度 |
|------|------|----------|
| **清单类** | "开工前 15 件必买物品" | ⭐⭐⭐⭐⭐ |
| **表格类** | "广州装修报价参考表 2026" | ⭐⭐⭐⭐⭐ |
| **工具类** | "Python 自动算面积的脚本" | ⭐⭐⭐⭐ |
| **教程类** | "防水施工三步法" | ⭐⭐⭐⭐ |
| **经验类** | "签合同 7 大避坑点" | ⭐⭐⭐⭐ |

**降低获取难度的方法**:
```
✅ 提供 PDF 下载链接
✅ 做成可截图收藏的长图
✅ 用 Excel 模板一键套用
✅ 整理成「复制粘贴」话术
```

---

### S - Stories (故事载体)

**核心问题**: "人们如何记住信息？"

**设计原则**:
```markdown
叙事 > 数据
故事是信息的容器
好的故事自带传播力
```

**五幕剧结构模版**:

```
第一幕：主角引入
"我是个程序员，完全不懂装修"

第二幕：冲突爆发  
"第一次签合同就被坑了 3000 块定金"

第三幕：努力尝试
"研究了 7 天，问了 15 个朋友，翻烂了 20 份合同"

第四幕：转折点
"直到我发现了一个 Excel 公式..."

第五幕：结局升华
"现在我会了，你们也能学会！(附教程)"
```

**案例改写**:

```
❌ 平淡版:
"装修时要注意审核报价单，避免增项。"

✅ 故事版:
"签合同时我没敢细看，结果结算时多了 2 万多!
工人说'这是行业潜规则'，但我不信邪😤
花了一周研究，终于找到了报价陷阱的检测方法
分享给大家，希望你们都能避开这个坑💪"
```

## 🧮 **STEPPS 评分系统**

### 自动化评估逻辑

```python
def stepps_score(content):
    score = {
        'social_currency': score_social_currency(title, hook),
        'triggers': find_trigger_affinity(topic),
        'emotion': detect_emotional_intensity(body),
        'publicity': assess_visual_distinctiveness(cover_style),
        'practical_value': count_actionable_items(content),
        'story_quality': evaluate_narrative_arc(structure)
    }
    
    # 加权总分 (每维权重不同)
    total = (
        score['social_currency'] * 0.15 +
        score['triggers'] * 0.10 +
        score['emotion'] * 0.20 +
        score['publicity'] * 0.10 +
        score['practical_value'] * 0.25 +
        score['story_quality'] * 0.20
    )
    
    return {
        'total': total,
        'weaknesses': [k for k,v in score.items() if v < 70],
        'recommendations': generate_improvements(score)
    }
```

### 达标标准

| 维度 | ≥90 分 | 70-89 分 | <70 分 |
|------|-------|---------|--------|
| Social Currency | 稀缺独特 | 有价值 | 平庸无亮点 |
| Emotion | 强烈情绪波动 | 中等情绪 | 无情绪色彩 |
| Practical Value | 即拿即用 | 部分可用 | 空洞理论 |
| Story Quality | 完整故事弧光 | 有起承转合 | 纯陈述 |

## 🎯 **实际应用案例**

### 案例 1: 《装修避坑指南》

原始版本:
```
装修时有很多需要注意的地方。
首先要注意材料质量，其次要注意施工流程...
```

STEPPS 优化版:
```
标题：装修公司不敢说的 7 个秘密‼️

P1: 真人出镜愤怒表情 + "差点被骗 3 万!"
P2-P3: 每个坑配一张证据截图 (聊天记录/报价单)
P4: "第 5 个最离谱 - 工人竟然这样说..."
P5: 总结表格 + "保存这张图防身"
P6: 提问互动："你还遇到过哪些奇葩事？评论区聊聊"
```

**STEPPS 得分**:
- Social Currency: 92 ("知道的人很少")
- Triggers: 65 (需加强日常场景绑定)
- Emotion: 88 (愤怒 + 惊讶)
- Publicity: 85 (固定封面风格)
- Practical Value: 95 (表格可直接用)
- Story: 80 (故事性强)

→ 总分：**84/100** ✅ 良好
