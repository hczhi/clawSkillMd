# 好坏案例对比库

> 用于快速理解优秀 vs 平庸的内容差异

---

## 📊 **案例 1: 装修合同避坑**

### ❌ 坏案例 (AI 化严重)

```markdown
标题：装修合同避坑指南

内容：
装修是一项复杂的工程，需要注意很多问题。首先要做好预算规划。
其次要选择靠谱的装修公司。最后要在施工过程中严格监督。

建议大家在签合同前仔细阅读每一条款，避免后期增项。希望这些建议能帮助到大家。
```

**问题分析**:
- AI 评分：8/10 🔴
- STEPPS 得分：42/100 🔴
- 人设一致度：15/100 🔴

**致命问题**:
1. "首先/其次/最后" - 逻辑词过多
2. "希望大家..." - 标准化结尾
3. 全篇无具体数字
4. 没有个人经历和情感表达
5. 语调像教程而非朋友聊天

---

### ✅ 好案例 (真实感 +MrBeast 风格)

```markdown
标题：签合同时我差点被骗 3 万块😱

内容：
本来以为签完就万事大吉了，结果结算时多了 2 万多!💔

工人说「这是行业潜规则」，但我不服输😤
花了一周把整个报价单用 Excel 重新算了一遍
居然发现了 17 处猫腻!!!🚨

作为一个程序员的强迫症，我就是咽不下这口气!
现在我把这份「报价单检查清单」整理出来了
需要的评论区扣「清单」
希望能帮你们避开我这个大坑💪

P.S. 最后追回来了 2 万，够买台新电脑了🖥️
```

**优势分析**:
- AI 评分：<2 分 ✅
- STEPPS 得分：84/100 ✅
- 人设一致度：90/100 ✅

**成功元素**:
1. 情绪冲击开头："差点被骗 3 万" + emoji
2. 具体数字支撑："2 万多" / "17 处猫腻" / "2 万"
3. 故事弧线：冲突→不服输→研究→反转→结局
4. 工具推荐："Excel 重新计算"
5. 利他价值："评论区扣清单"
6. 真实感："作为程序员的强迫症"

## 📊 **案例 2: 防水施工注意事项**

### ❌ 坏案例

```markdown
标题：卫生间防水怎么做？完整攻略来了！

内容：
防水是装修中非常重要的一环。如果做得不好，后期会出现渗漏问题。

正确的做法是：
1. 墙面高度至少 1.8 米
2. 地面要刷两遍
3. 闭水试验要做 48 小时
4. 门口要做止水墩

以上就是全部内容，祝大家装修顺利!
```

**问题诊断**:
- 缺乏情绪张力
- 纯教程口吻，没有个人体验
- 没有具体数据
- 结尾过于正式

---

### ✅ 好案例

```markdown
标题：本来只刷了 30cm，楼下邻居找上门投诉渗水...😭

内容：
当天我就崩溃了!💔
连夜补刷到 1.8 米，现在才敢放心闭水试验✅

这件事让我学到了：
❌ 干区不要省，淋浴区必须 1.8m
❌ 至少刷两遍，第一遍干了再刷第二遍
❌ 闭水试验不能少于 48h，楼下要来确认
❌ 门口一定要做止水墩，不然隔壁墙也会发霉

防水涂料用了两桶，花费¥480，比预算超了¥80
但现在想想...多花这点钱总比后期砸墙重装划算吧?

作为一个第一次装修的小白，我当时真的以为刷高一点就够了...
幸好发现得早，不然又要赔钱了💸

有不懂的评论区问我，看到都会回❤️
```

**成功要素**:
- 冲突开场："被投诉渗水" → 引发好奇
- 情绪曲线：崩溃→补救→学到教训→庆幸
- 细节丰富：¥480、超了¥80、两桶涂料
- 成长轨迹：小白→有经验
- 互动引导："有问题评论区问"

## 📊 **案例 3: 预算控制**

### ❌ 坏案例

```markdown
标题：如何控制装修预算？5 个技巧分享

内容：
预算控制是装修中非常重要的环节。以下是 5 个实用技巧:

1. 制定详细预算表
2. 优先满足必要支出
3. 预留 10% 应急资金
4. 定期核对实际支出
5. 严格控制增项

希望以上方法能帮助你有效控制预算!
```

**问题**:
- 空洞无实质
- 全是理论无数据
- 没有故事性
- 读者看完不知道从何下手

---

### ✅ 好案例

```markdown
标题：花了 128,750 元的真实账单公开，平均每个坑¥7,573😅

内容：
总共踩了 17 个坑，每个坑的平均成本：¥7,573

最初预算：10 万
最终结算：128,750 元
超支比例：+28.75%

其中最大的三个坑:
1️⃣ 报价单漏项 +¥12,300
2️⃣ 水电绕线收费 +¥8,400  
3️⃣ 瓷砖补货加价 +¥5,200

最气的是工人说「这是行规，大家都这么收」
但我这个程序员的强迫症就是咽不下这口气😤

花了一周用 Excel 把所有项目重新核算一遍
居然找到了 23 处可疑收费!!!

表格已经整理好放在共享文档里
需要的评论区扣「账单」
希望你们都能少踩几个坑💪

附：我的超支复盘表截图👇
[配图：Excel 表格截图]
```

**成功点**:
- 数字冲击："128,750 元"/"17 个坑"/"+28.75%"
- 真实性：具体的三项超支明细
- 情绪共鸣：愤怒 + 不服输
- 工具推荐：Excel 重算 + 共享文档
- 利他行动：评论扣关键词获取

| 维度 | 坏案例特征 | 好案例特征 |

| **结尾方式** | "感谢关注" | "评论互动" |

| **预期 AVD** | <15 秒 | >35 秒 |
